A Text-to-SQL prompting pipeline that builds an SQL DB from scratch using a variety of large language models. Inducing an ontology from dialogues using this method reaches state-of-the-are in task-oriented dialogue ontology construction. This shows that LLMs can communicate with an SQL DB to build and expand it. See [arxiv](https://arxiv.org/abs/2507.23358) and [github](https://github.com/renatovukovic/text-to-sql-llm-ontology-construction).
